## About

A reference CircleCI pipeline built for the Field Engineer take-home exercise: custom Docker image build, Postgres sidecar integration tests, OIDC-authenticated publish to Amazon ECR, and dynamic config that skips build/test/publish on docs-only changes (this line is a test of exactly that).
